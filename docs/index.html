What it does

三个能力，一条链路

边缘推理、运动控制、无线交互 —— 每层都能单独替换，组合起来是一台能自己走直线的车。

Edge AI

ESP-DL 加载 INT8 量化模型，逐像素二分类找出引导线。

  • U-Net 轻量变体，1 输入通道
  • Sigmoid 查表后处理，零浮点开销
  • 知识蒸馏压缩教师模型 160 倍

Motion

质心偏差喂进 PID，双轮差速跟线；编码器兼做碰撞检测。

  • G1 / G2 双质心，近远参考抗抖动
  • 滑动窗口掉速检测，无额外传感器
  • 连续丢线 5 帧自动刹车

Control

微信小程序原生实现，局域网直连，不依赖任何云服务。

  • TCP 命令通道 + UDP 视频流
  • 实时分割叠加图回传
  • 双分区 OTA 空中升级

数据怎么流动

一条从像素到轮速的最短路径，中间没有操作系统、没有云端。

↓

Get Started

30 分钟跑起来

仓库自带训练好的 model.espdl，克隆下来编译烧录即可循迹。

PowerShell / Bash 
# 1. 克隆（务必带子模块，否则小程序目录是空的）
git clone --recurse-submodules \
  https://github.com/AishuaiYao/AICleanBot.git
cd AICleanBot

# 2. 安装 ESP-IDF v5.4.x 后，设定目标芯片
idf.py set-target esp32s3

# 3. 编译 + 烧录 + 串口监视（Windows 用 COM3 之类）
idf.py -p COM3 build flash monitor

烧录之前请确认

  • 模组带 PSRAM（`CONFIG_SPIRAM=y` 已开，无 PSRAM 会在 esp_camera_init 崩）
  • 摄像头 D0–D7 顺序正确 —— 唯一没有报错提示的坑
  • TB6612 的 STBY 已拉高，否则电机完全不动
  • 电池分压用 100k + 10k，ADC 不能直连 12V
  • main/models/model.espdl 存在（编译期嵌入固件）

Roadmap

这不是一个做完的项目

因为硬件资金等原因暂停在 V1。路线已经想清楚了，欢迎接手任何一段。

V1 · 视觉巡线 已实现

ESP-DL 边缘分割、PID 循迹、编码器碰撞检测、双通道通信、OTA。

V1.1 · 清洁机构 已实现

3 号电机驱动毛刷/吸水辊，水箱与结构件完成 3D 建模。

V2 · 地图与导航 进行中

DFS 全覆盖遍历（原型在 py_scripts/simulation/dfs.py）移植到板端 C++，配合里程计构建栅格地图。

V3 · 自主清扫 计划

覆盖路径规划 + 边界识别 + 回充对接，形成完整清洁闭环。

V4 · 更强的 AI 构想

多类别分割（地面材质、障碍物、充电桩），端侧多任务模型。

正在寻找的协作

  • 硬件：PCB 打样与贴片支持，尤其是载板小型化
  • 算法：全覆盖路径规划、视觉里程计
  • 工程：CI（固件自动编译 + 训练冒烟测试）
  • 文档：英文翻译、拆解图解

已知限制

  • 模型只分背景 / 引导线两类
  • 左右轮 IN1、IN2 共用 GPIO，无法原地自转
  • WiFi 密码与 PID 增益仍硬编码在源码里
  • 无单元测试，靠手工流程验证
